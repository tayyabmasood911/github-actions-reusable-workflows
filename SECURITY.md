# Security Policy

## Supported Versions

Only reusable workflows maintained on `main` and pinned release tags (e.g., `@v1`) receive security updates.

| Version | Supported          |
|:--------|:------------------:|
| main    | :white_check_mark: |
| < main  | :x:                |

## Reporting a Security Vulnerability

If you discover a secret exposure vulnerability, workflow privilege escalation flaw, or untrusted script execution vector:

1. **Do not create public GitHub issues or pull requests**.
2. Email maintainer **Tayyab Masood** at **tayyabmasood911@gmail.com** with the subject `[SECURITY] Reusable Workflow Vulnerability`.
3. Provide details of the workflow, inputs/secrets involved, and a reproduction proof-of-concept.

All security reports will be acknowledged within 24 hours.
